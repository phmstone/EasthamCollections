# J. W. Eastham's Collections


John William Eastham was a plant pathologist and botanist active in British Columbia in the years 1914-1968. The R scripts in this repository were used to generate the statistics and plots for a publication about Eastham's life and collections. 

The scripts rely on data from [GBIF](https://www.gbif.org/), and a GBIF account will be needed to use them. Make a GBIF account by clicking "REGISTER" [here](https://www.gbif.org/user/profile). 


### Input Files


The scripts will generate most of data needed for the analyses. Three input files are needed; a list of all vascular plant species found in Canada and their distribution, a list of species excluded from Eastham's "Supplement to the Flora of Southern British Columbia" (1947), and a shape file of the railways of British Columbia.   

The vascular plant information can be generated by using the [Checklist builder](https://data.canadensys.net/vascan/checklist?lang=en) from [VASCAN](https://data.canadensys.net/vascan/search) to make a checklist of all species for all Provinces and Territories in Canada. 
  
The list of species excluded from Eastham's supplement is uploaded as a .csv file [here](https://github.com/phmstone/EasthamCollections/blob/main/data/Eastham_addendumExcluded.csv).    

The shapefile for railways of British Columbia can be downloaded from the [British Columbia Data Catalogue](https://catalogue.data.gov.bc.ca/dataset/railway-track-line).

### Scripts

The scripts should be run in the same environment in the same order that they are listed in this table. Users will need to update [GBIF-download.R](https://github.com/phmstone/EasthamCollections/blob/main/scripts/GBIF-download.R), [collectorsBC.R](https://github.com/phmstone/EasthamCollections/blob/main/scripts/collectorsBC.R), and [compassPlot.R](https://github.com/phmstone/EasthamCollections/blob/main/scripts/compassPlot.R) with their own GBIF login credentials in order to use them. 
Search for `# GBIF credentials` in the scripts to find the portions to modify.

| Script | Function |
| ------ | ----------- |
| GBIF-download.R | Downloads data from GBIF for herbarium specimens collected by Eastham. |
| GBIF_cleaner.R | Performs spatial and temporal checks to clean data, and outputs basic statistics about Eastham's collections. |
| VasCan-cleaner.R    | Ensures that special characters used in VASCAN are handled correctly for GBIF data. |
| collectorsBC.R | Downloads data from GBIF to determine which were the most prolific collectors in BC during the years Eastham was active in BC. |
| Eastham-Firsts-maps.R    | Compares Eastham's collections to other specimens of the same species in North America to see which were the "first" collection for Canada or British Columbia, and plots the results on a map of British Columbia with railways. |
| easthamTaxonomy.R | Links Eastham's British Columbian collection data from GBIF to VASCAN to determine the distribution status for each species collected in BC. |
| Eastham_Excluded_BC.R    | Links the species Eastham excluded from his 1947 "Supplement to the Flora of Southern British Columbia" to VASCAN to determine the present day distribution status for each species.|
